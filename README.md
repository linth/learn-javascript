# learn-javascript

## Basic 

### 變數和資料型別 (Variable and Data Type)
- 變數宣告（var、let、const）、作用域
- 基本資料型別（數字、字串、布林值、null、undefined）
- 複合資料型別（物件、陣列、函式）

### 運算子 (Operator)
- 算術運算子（+、-、*、/、%）
- 關係運算子（==、!=、===、!==、<、>、<=、>=）
- 邏輯運算子（&&、||、!）
- 指定運算子（=、+=、-=、*=、/=、%=）

### 流程控制 (Control Flow)
- 條件語句（if、else if、else）
- 迴圈（for、while、do...while）
- switch 語句
- break、continue、return

### 函式 (Function)
- 函式宣告和呼叫
- 參數和返回值
- 匿名函式和箭頭函式
- 函式遞迴
- closure
- this
- prototype

### 物件導向程式設計（Object-Oriented Programming, OOP）
- 物件和類別
- 建構函式和原型
- 繼承和原型鏈
- 封裝和多型

### 陣列 (Array)
- 陣列的宣告和初始化
- 存取和修改元素
- 陣列的方法（如 push、pop、shift、unshift、splice 等）

### 非同步編程 (Asynchronous Programming)
- callback function
- Promise
- async/await
- async (event-loop) => `重要`

### 錯誤處理 (Error Handling)
- try-catch-finally

### 模組化程式設計 (Module System)
- import 和 export
- CommonJS 和 ES6 模組

### 資料結構 (Data Structure)
- Array（陣列）
- Object（物件）
- Map（鍵可以是任何類型）
- Set（不重複集合）
- WeakMap / WeakSet
- 自行實作常見結構  => `重要`
- Stack
- Queue
- Linked List
- Binary Tree
- Hash Table

### 演算法 (Algorithm)
- 排序：Bubble, QuickSort, MergeSort
- 搜尋：Binary search
- 遍歷：DFS、BFS
- 時間複雜度 Big-O：O(1), O(n), O(log n), O(n log n)
- 空間複雜度 Big-O：O(1), O(n), O(log n), O(n log n)

### DOM 操作
- 取得 DOM 元素
- 修改元素屬性和內容
- 事件處理
